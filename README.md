## ¿Qué es esto?

Este no es solo un programa. Es el **núcleo tecnológico** de un ecosistema editorial destinado a transformar conocimiento en experiencias de aprendizaje.

La primera piedra de ese ecosistema es el **GAC**: una máquina capaz de construir crucigramas automáticamente, pero construida sobre una base sólida: el dominio del crucigrama mismo.

&gt; *"El algoritmo debe adaptarse al dominio; el dominio nunca debe adaptarse al algoritmo."*
